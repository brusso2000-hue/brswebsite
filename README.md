# brsmove.com — Business Relocation Services

Static, framework-free rebuild of https://brsmove.com. Every page from the old WordPress site keeps its
original URL, so existing search rankings and backlinks carry over.

- `index.html`, `*/index.html` — generated pages (deploy the repo root as-is to any static host)
- `assets/` — CSS, JS, logo, WebP images
- `tools/build.py` + `tools/content.json` — generator and the content it reads. Edit, then run `python3 tools/build.py` (needs Pillow)
- `sitemap.xml`, `robots.txt` — SEO files, regenerated by the build

## Quote form
Forms open the visitor's email app until you set `FORM_ENDPOINT` in `tools/build.py` (Formspree, FormSubmit,
Netlify Forms, etc.) and rebuild. Submissions then POST there and redirect to the matching `/thank-you-*/` page.
